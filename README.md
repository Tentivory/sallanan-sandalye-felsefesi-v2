# Sallanan Sandalye Felsefesi v2

## Giriş

Bu proje, insanlığın binlerce yıldır peşinde koştuğu en temel soruyu çözmek için tasarlanmıştır: **"Sallanan sandalyede otururken aklıma ne geliyor?"**

Evet, doğru duydunuz. Artık bu soruya cevap verecek bir yazılım var. Bilim dünyası şu anda şokta.

## Özellikler

- Tamamen rastgele felsefi sözler üretir.
- Her çalıştırılışında evrenin anlamını 0.0001% daha az anlamanızı sağlar.
- CPU'nuzu gereksiz yere yorar, bu da size "düşünüyorum" hissi verir.
- Hiçbir şey yapmaz ama çok ciddi görünür.

## Kullanım

```bash
python sallanan_sandalye.py
```

Çıktı örneği:

> "Sallanan sandalye aslında zamanın kendisidir. İleri geri... ileri geri..."

## Uyarılar

- Bu programı çalıştırdıktan sonra hayata dair ciddi kararlar almayın.
- Aşırı kullanım durumunda varoluşsal kriz garantilidir.
- Sallanan sandalye sahibi değilseniz program %87 daha az çalışır.
